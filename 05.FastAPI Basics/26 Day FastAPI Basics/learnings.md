## Setup Hiccups Before Any FastAPI Code

A few false starts just activating the virtual environment —

```bash
source venv\bin\activate   # backslashes — Windows-style path, doesn't work in bash
source ven/bin/activate    # typo — "ven" instead of "venv"
```

Both failed with "No such file or directory." Linux paths always use forward slashes, and the folder is named `venv`, not `ven`. Also turned out `python3-venv` itself needed installing fresh —

```bash
sudo apt update
sudo apt install python3-venv
```

After that, the real activation worked —

```bash
source venv/bin/activate
pip install fastapi uvicorn
```

Installed cleanly, pulling in `starlette`, `pydantic`, `uvicorn`, and a handful of smaller dependencies FastAPI needs underneath.

## Exercise 1 — First Endpoint

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Iris MLOps API is running"}
```

```bash
uvicorn main:app --reload
```

```
Uvicorn running on http://127.0.0.1:8000
INFO: 127.0.0.1:34362 - "GET / HTTP/1.1" 200 OK
```

`main:app` tells uvicorn exactly where to find the FastAPI instance — file `main.py`, variable `app`. The `--reload` flag means every time the file is saved, the server restarts itself automatically — no manually stopping and starting during development.

Tested from a second terminal —

```bash
curl http://127.0.0.1:8000
# {"message":"iris Mlops API is running"}
```

The exact JSON dictionary written in Python came back as a JSON response with zero extra serialization code. FastAPI handles converting the Python dict to a JSON body automatically.

## Exercise 2 — Path Parameters

```python
@app.get("/models/{model_name}")
def get_model(model_name: str):
    return {"model_name": model_name, "status": "active"}
```

```
INFO: "GET /models/iris-classifier HTTP/1.1" 200 OK
```

```bash
curl http://127.0.0.1:8000/models/iris-classifier
# {"model_name":"iris-classifier","status":"active"}
```

`{model_name}` inside the URL path becomes a variable. FastAPI matches it directly to the function argument named `model_name` — same name, no extra wiring needed. Worked correctly on the first attempt.

## Exercise 3 — Query Parameters (and a real syntax error)

First attempt at adding the `/predict` endpoint crashed the server entirely —

```
File "main.py", line 14
    def predict(feature1: float, feature2: float, feature3: float, feature4: float)
                                                                                   ^
SyntaxError: expected ':'
```

Missing the colon at the end of the function definition line. Python's error pointed exactly at the spot where it expected one — a clean, specific error message that made the fix obvious. Added the colon —

```python
@app.get("/predict")
def predict(feature1: float, feature2: float, feature3: float, feature4: float):
    return {
        "input": [feature1, feature2, feature3, feature4],
        "prediction": "setosa"
    }
```

Server started clean after the fix —

```
INFO: "GET /predict?feature1=5.1&feature2=3.5&feature3=1.4&feature4=0.2 HTTP/1.1" 200 OK
```

```bash
curl "http://127.0.0.1:8000/predict?feature1=5.1&feature2=3.5&feature3=1.4&feature4=0.2"
# {"input":[5.1,3.5,1.4,0.2],"prediction":"setosa"}
```

This is the exact same `?key=value&key=value` query string pattern from Day 21 and Day 22 — except this time it's the API being built, not the API being called. FastAPI reads each query parameter straight from the URL and passes it into the function as a properly typed float, no manual parsing required.

## What Actually Happened Underneath

Every test today produced a `200 OK` line in the uvicorn log — that's the exact status code concept from Day 21 showing up automatically, generated by FastAPI without writing a single `return Response(status_code=200)` anywhere. The same goes for the JSON body — every dict returned from a function became a properly formatted JSON response with the correct `Content-Type` header, all handled by FastAPI behind the scenes.

## What to Remember

| Concept | What it means |
|---|---|
| `app = FastAPI()` | creates the application instance |
| `@app.get("/path")` | registers a function to handle GET requests at that path |
| `uvicorn main:app --reload` | runs the server, auto-restarts on file changes |
| `{model_name}` in path | path parameter, matched to function argument by name |
| Query parameters | regular function arguments, filled from `?key=value` in the URL |
| Returning a dict | FastAPI auto-converts it to a JSON response |
| `/docs` | auto-generated interactive API page, built from type hints |
