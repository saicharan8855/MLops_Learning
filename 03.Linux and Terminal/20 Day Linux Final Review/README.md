## key commands mastercards
- navigation : pwd , cd , ls
- files : touch , cat , cp , mv , rm , mkdir
- reading : head , tail , less , wc
- searching : grep , grep -E , find
- Piping : |,>,>>
- scripting : functions, if/else, for, while, arrays
- environment: export , $VAR , $?
- permissions : chmod +x


## Biggest Lessons
- A frozen terminal usually means a command is waiting on stdin
- grep needs a file argument or it hangs
- bash [ ] needs spaces around it or it breaks
- $? only reflects the command immediately before it
- Always quote variables in conditions
